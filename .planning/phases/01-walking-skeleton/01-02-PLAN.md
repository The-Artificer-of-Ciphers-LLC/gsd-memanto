**As a** GSD project owner, **I want to** install the Memanto capability once globally, enable it in one project, and watch a real discuss-phase run pass or halt on a Memanto gate, **so that** a misconfigured or unhealthy Memanto blocks the workflow instead of silently failing open.

Purpose: after this plan the owner sees one actionable line per real problem, and a healthy project passes.

</objective>

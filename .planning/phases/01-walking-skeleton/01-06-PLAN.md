## Phase Goal

**As a** GSD project owner, **I want to** install the Memanto capability once globally, enable it in one project, and watch a real discuss-phase run pass or halt on a Memanto gate, **so that** a misconfigured or unhealthy Memanto blocks the workflow instead of silently failing open.

<objective>
Give the owner `gsd_run memanto doctor` (and the direct `node …/memanto.cjs doctor` form) that reports every Phase-1 fail-open state as an error — enabled but not loaded, not consented, outside engines.gsd, not rendering at a declared point (GATE-06, D-17 to D-21, OD-3) — plus the gate's own checks, and prove the bundle is zero-dependency, synchronous and stateless (INST-05).

Purpose: the gate fails open whenever gsd-core does not load it; doctor is how the owner sees that.
Output: memanto.cjs, lib/gsd-host.cjs, scripts/check-probe.cjs, the manifest commands entry, doctor and bundle tests.
</objective>

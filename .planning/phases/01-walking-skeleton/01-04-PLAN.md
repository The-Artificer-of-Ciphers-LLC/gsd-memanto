## Phase Goal

**As a** GSD project owner, **I want to** install the Memanto capability once globally, enable it in one project, and watch a real discuss-phase run pass or halt on a Memanto gate, **so that** a misconfigured or unhealthy Memanto blocks the workflow instead of silently failing open.

<objective>
Prove, with gsd-core's own loader, validator and dispatch scanner as the oracle, that the installed manifest loads with zero warnings (INST-02), that every declared hook sits at a (point, kind) the host really dispatches (INST-03), and that the manifest avoids every loader trap that silently drops a capability (INST-04). Each trap is reproduced by a negative fixture so the test proves the trap is real.

Purpose: the owner's install can never "succeed" while the gate silently never runs on either supported host version.
Output: three conformance test files.
</objective>
